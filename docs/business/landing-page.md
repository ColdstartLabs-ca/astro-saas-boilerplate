## Design Direction

### Visual Style

- **Clean, modern SaaS aesthetic** - Similar to Vercel, Linear, Stripe
- **Dark mode option** - Many developers/marketers prefer dark
- **Generous whitespace** - Let content breathe
- **Subtle gradients** - Modern but not flashy

### Color Psychology

- **Primary:** Green (growth, money, go) - for CTAs
- **Secondary:** Blue (trust, reliability) - for features
- **Accent:** Purple/indigo (innovation, AI) - sparingly

### Typography

- **Headlines:** Bold, modern sans-serif (Inter, Cal Sans)
- **Body:** Readable, clean (Inter, system fonts)
- **Code/Technical:** Monospace for any technical elements

### Imagery

- **Product screenshots:** Real UI, not mockups
- **Illustrations:** Minimal, purposeful (avoid generic stock illustrations)
- **Icons:** Consistent set (Lucide, Heroicons)
- **Animations:** Subtle, purposeful (not distracting)

### Mobile Considerations

- **Mobile-first approach** - 60%+ traffic likely mobile
- **Sticky CTA** on mobile
- **Collapsible comparison table**
- **Touch-friendly tabs**

## Copy Guidelines

### Tone of Voice

- **Confident** but not arrogant
- **Direct** - no fluff or jargon
- **Empathetic** - we understand their pain
- **Specific** - numbers and proof over vague claims

### Words to USE

- Autopilot, automated, hands-off
- Human-quality, publish-ready
- Reliable, stable, works
- Scale, growth, traffic
- Simple, easy, fast

### Words to AVOID

- "Leverage AI" (overused)
- "Revolutionary" (hyperbolic)
- "Best-in-class" (meaningless)
- "Cutting-edge" (cliché)
- "Synergy" (corporate speak)

### Competitor References

- Be factual, cite sources (reviews, ratings)
- Focus on customer pain points, not attacks
- Let comparison tables speak for themselves
- Use phrases like "Unlike [competitor]..." sparingly

## Technical Requirements

### Performance

- **LCP < 2.5s** (Core Web Vital)
- **Lazy load images** below fold
- **Preload critical fonts**
- **Optimize hero image** (WebP, compressed)

### Analytics

- **Google Analytics 4** - page views, scroll depth, CTA clicks
- **Hotjar/FullStory** - heatmaps, session recordings
- **Conversion tracking** - trial signups, demo requests

### A/B Testing

- Test headlines (problem vs. solution focus)
- Test CTA copy ("Start Free Trial" vs. "Get Started Free")
- Test pricing display (show vs. hide on landing page)
- Test social proof placement
