## Why Documents Are Archived

Documents are moved to this archive when:

1. **Resolved Issues** - The problems identified have been fixed
2. **Implementation Complete** - Features described are now in production
3. **Historical Reference** - Useful for understanding past decisions
4. **Outdated Paths** - References legacy code paths that no longer exist

## Using Archived Documents

When referencing archived docs:

- **Do NOT** use them as current implementation guides
- **DO** use them to understand historical context
- **Always** check the main documentation for current status
- **Cross-reference** with the [Capability Status Matrix](../technical/capability-status-matrix.md)
